Logos dos bancos
================

Coloque aqui os arquivos PNG das logos. O app procura por estes nomes exatos:

  bradesco.png
  bb.png        (Banco do Brasil)
  brb.png
  c6.png

Dicas:
- Use PNG quadrado, de preferência com fundo transparente.
- Tamanho recomendado: 128x128 ou 256x256 pixels.
- Se um arquivo não existir, o app mostra automaticamente um círculo
  colorido com a sigla do banco (não quebra nada).

Para adicionar outros bancos, peça para incluir o nome no codigo
(em BANK_BRANDS, dentro de public/index.html) com o nome do arquivo .png.
